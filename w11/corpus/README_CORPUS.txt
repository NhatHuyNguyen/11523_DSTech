Week11_Corpus - DSTS 11523 Data Science Technology and Systems (University of Canberra)
======================================================================================

What this is: the course's own Week 1-6 tutorials, used as the document collection (corpus)
for the Week 11 lab, where you build a RAG 'Course TA' that answers questions about these
tutorials and cites [week, file, section].

The files are unchanged copies of the lecturer's tutorial files (byte-identical, SHA-256 checked).
Format: Markdown (.md), plain UTF-8 text. Open them in any text editor or in VS Code / Jupyter.
Word counts are whitespace-separated tokens in the raw file (code blocks included).

For students of DSTS 11523 only. Do not redistribute.
